# Лабораторная работа №3 - каталог учебных аудиторий на Python

## Описание проекта

Проект представляет собой пакет для хранения и поиска учебных аудиторий.
Каталог можно сохранить в JSON и загрузить из файла.

Запись об аудитории состоит из шести полей.

- `item_id` — уникальный строковый идентификатор
- `name` — название аудитории
- `category` — категория, например лекционная или компьютерная
- `year` — год открытия
- `capacity` — количество мест
- `has_projector` — есть ли в аудитории проектор

**1. Проверка данных.** Класс `Classroom` создан с помощью `dataclass`. При создании аудитории проверяются поля. Строки должны быть непустыми, год должен быть целым числом от 1 до текущего года, а количество мест — положительным целым числом. Для наличия проектора используются `True` и `False`.

**2. Работа с каталогом.** Класс `Catalog` позволяет добавлять аудитории, получать их по ID и удалять. Каждый ID может встретиться в каталоге только один раз.

**3. Поиск.** Метод `find_by_category` ищет по точному названию категории. Метод `find_by_name` ищет по части названия аудитории без учёта регистра.

**4. Сохранение и загрузка.** Метод `save` записывает каталог в JSON, а `load` восстанавливает его из файла.


Выбери интерпретатор из `.venv` в настройках проекта. Следующие команды выполняй в терминале PyCharm с активным окружением `.venv`.

**Запуск программы.**

```
python -m src.main
```

Программа добавляет две аудитории, показывает поиск, сохраняет каталог в `classrooms.json` и загружает его. После загрузки она удаляет аудиторию с ID `a101` из загруженного каталога и выводит количество оставшихся записей. При каждом запуске пример заново записывает демонстрационные данные в `classrooms.json`.

## Примеры использования

**Добавление аудитории и поиск по названию.**

```python
from src.catalog import Catalog, Classroom

catalog = Catalog()
room = Classroom("a101", "Аудитория 101", "лекционная", 2020, 30, True)
catalog.add(room)

print(catalog.get("a101").name)
print(catalog.find_by_name("АУДИТОРИЯ"))
```

**Загрузка каталога из файла.** Этот пример можно выполнить после запуска `src.main`, когда файл `classrooms.json` уже создан.

```python
from src.catalog import Catalog

catalog = Catalog()
catalog.load("classrooms.json")
print(len(catalog))
print("a101" in catalog)
```

## Обработка ошибок

Ошибки каталога наследуются от `CatalogError`.

| Исключение | Когда возникает |
| --- | --- |
| `InvalidClassroomError` | У аудитории неверные поля или в каталог добавляют объект другого типа |
| `DuplicateIdError` | Такое значение ID уже есть в каталоге |
| `ItemNotFoundError` | Запрошенной или удаляемой аудитории с таким ID нет |
| `UnsupportedFormatVersionError` | В файле указана неизвестная версия формата |
| `CorruptedFileError` | Файл недоступен, JSON повреждён или записи в нём неверны |

## Как работает каталог

Аудитории хранятся в словаре по ID. Метод `get` в среднем работает за `O(1)`.
Метод `find_by_name` перебирает все аудитории, поэтому выполняет `O(n)` проверок
названия для `n` записей. Оба метода поиска возвращают новые списки.

`len(catalog)` возвращает количество аудиторий, а `item_id in catalog` проверяет,
есть ли такой ID. Цикл `for` обходит аудитории в порядке их добавления.

В JSON записываются версия формата `format_version` и список `items` со всеми
полями аудиторий. При загрузке записи сначала проверяются во временном
каталоге. Если файл прочитан полностью и все записи верны, новый каталог
заменяет старый. При ошибке прежние данные сохраняются.
